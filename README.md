# Estoque e Serviços (React + Supabase)
1. Crie um projeto em supabase.com e rode `supabase/schema.sql` no SQL Editor.
2. Copie `.env.example` para `.env` e preencha URL e chave anon (Project Settings > API).
3. `npm install` e `npm run dev`.
4. Em produção, hospede a pasta `dist` (`npm run build`) na Vercel ou Netlify.
